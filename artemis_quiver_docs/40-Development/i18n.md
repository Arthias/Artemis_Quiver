# i18n Multi-Language Support

## Stack

- **react-i18next** + **i18next-browser-languagedetector**
- Init in `src/app/i18n/index.ts`
- Wrapped at `AppProviders` level via `<I18nextProvider>`

## Adding a Language

1. Create `src/app/i18n/locales/xx.json` (copy `en.json` as template)
2. Translate all values — keys stay identical
3. `import.meta.glob` auto-discovers the file — no manual imports

## Key Conventions

```
page.component.element
```

Examples: `analysis.analyze`, `profile.saveChanges`, `config.llmProvider`, `nav.settings`

## Type Safety

`src/app/i18n/i18next.d.ts` augments `react-i18next` `CustomTypeOptions`. Mistyped keys fail at `tsc --noEmit`.

## Extension i18n

- `src/extension/i18n.ts` — lightweight `t()` helper for background service worker & overlay
- Locale JSON copied to `Artemis_Quiver_extension/locales/` during `npm run build:ext`
- Popup uses standard `react-i18next`

## Rendering Engine

`renderCVToHTML()` / `renderCLToHTML()` accept optional `lang` param (default `"en"`).
Section headings use a locale-keyed map inside `src/components/cv/renderingEngine.ts`.
